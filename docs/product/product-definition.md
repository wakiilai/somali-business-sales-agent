# Product Definition

## User problem

Small Somali businesses often handle customer sales through manual messages, calls, notebooks, and spreadsheets. Leads are missed, product information is inconsistently verified, and follow-up is unreliable.

## First release

A web-chat sales workflow for one fictional electronics business, supporting Somali and English customer questions, verified product lookup, lead capture, quotation drafting, manager approval, follow-up tasks, and human handoff.

## Definition of done for the first vertical slice

A synthetic customer can ask about a catalog product, receive a response based only on verified catalog data, create one authorized lead, and produce a redacted audit trail. Replaying the request must not create a duplicate lead.
