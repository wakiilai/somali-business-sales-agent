# Out of Scope

The first release does not include:

- ERP integration.
- Real client/customer data.
- Autonomous payment, refund, order acceptance, stock reservation, discount, or delivery commitments.
- WhatsApp production messaging.
- Voice support before text workflow verification.
- Universal CRM or ERP schema.
- Arbitrary integrations selected by the model.
- Production deployment before staging and security evidence pass.
